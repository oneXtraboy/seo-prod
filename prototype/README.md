# Локальный прототип Synapsee

Автономный интерактивный прототип обновлённого сайта Synapsee по двум аудитам от 7 августа 2026 года и ТЗ от 10 августа 2026 года. Production-сайт не изменён, деплоя нет.

## Быстрый запуск

1. Дважды нажмите `ОТКРЫТЬ_ПРОТОТИП.cmd`.
2. Дождитесь сообщения о локальном адресе.
3. Браузер откроет `http://127.0.0.1:4173/`.
4. Для остановки закройте окно запуска или нажмите `Ctrl+C`.

Готовая сборка уже находится в `dist/`. Обычный просмотр не требует интернет-соединения. Внешние переходы в Telegram, телефон и email явно подписаны; скрытых сетевых запросов нет.

Обычный просмотр на Windows не требует Node.js, npm, установки зависимостей или прав администратора: комплект запускает готовую сборку встроенным PowerShell-сервером. Инструкция для принимающей стороны — в [НАЧАТЬ_ЗДЕСЬ_ФЕДОР.md](./НАЧАТЬ_ЗДЕСЬ_ФЕДОР.md).

## Команды разработки

Для изменения исходников и повторной сборки нужен Node.js 22.12 или новее.

```powershell
npm run dev
npm run build
npm run preview -- --host 127.0.0.1 --port 4173
```

Полная невизуальная проверка:

```powershell
npm run check
```

Отдельные проверки:

```powershell
npm run lint
npm run test
npm run check:links
npm run check:network
```

## Что реализовано

- 38 публичных маршрутов из sitemap и служебный `/_prototype/variants/`;
- 11 уникальных страниц услуг, 6 кейсов и 6 статей на общих data-driven шаблонах;
- выбор услуги по ситуации, фильтры кейсов и доказательств;
- двухшаговые локальные формы с валидацией и экраном успеха;
- доступное мобильное меню, Escape и возврат фокуса;
- FAQ, sticky-якоря, mobile bottom CTA и responsive-таблицы;
- конкретные подписи источников у измеримых показателей;
- A/B-варианты hero для главной, услуги и Pricing в desktop/mobile-режимах;
- статическая проверка маршрутов, ссылок и отсутствия runtime-сети;
- unit/component tests и smoke-render всех 38 маршрутов.

## Важные ограничения

- формы ничего не отправляют и не сохраняют;
- все визуальные рабочие документы — явно подписанные demo-placeholders;
- неподтверждённые показатели кейсов не представлены как доказанный вклад SEO;
- юридические и договорные сведения требуют отдельной проверки;
- визуальная приёмка не выполнена исполнителем: по ТЗ её делает Роман без автоматизации браузера.
